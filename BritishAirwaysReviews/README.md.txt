# ✈️ British Airways Reviews Dashboard – Tableau Public Project

This interactive dashboard, built with Tableau Public, explores customer review data for British Airways. The goal of the project was to identify trends in passenger feedback, highlight areas of customer satisfaction and dissatisfaction, and offer actionable insights for improving the airline experience.

## 📊 View the Dashboard

🔗 [View on Tableau Public](https://public.tableau.com/app/profile/achmidt.pierre.louis/viz/AchmidtFirstProject/Dashboard1)

---

## 🧠 Project Objectives

- Analyze the sentiment of customer reviews across different flight categories (e.g., economy, business)
- Explore common complaints and praises based on review scores
- Understand trends in ratings by:
  - Cabin type
  - Reviewer nationality
  - Departure and destination airports
- Identify possible improvement areas based on low-rated reviews

---

## 🧰 Tools Used

- **Tableau Public** – for data visualization
- **Excel/CSV** – for data cleaning (if applicable)
- **Text analysis techniques** – to group and visualize review keywords
